# TypeScript package router

This scope reproduces Rust-defined Keyless behavior for Node, browser, and React Native
consumers.

Before acting, apply the repository-root `AGENTS.md`, resolve every touched path with the
`context-resolve` skill, and read all mandatory knowledge. The resolver selects
`../docs/typescript-implementation.md`, shared cross-language contracts, and any
conformance, generated-file, security, CI, or release documents required by the task.

Re-run resolution when the change reaches Rust, Python, or the shared fixture. Do not put
TypeScript implementation rules or command inventories in this router.
